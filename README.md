# Pattern Proof

A browser-based seamless pattern checker and 300 PPI export tool.

## Features

- Compares the left/right and top/bottom edges of a pattern tile
- Shows a live repeated preview and a centered-seam inspection view
- Scales the pattern from 5% to 400%
- Exports an exact canvas size in inches at 300 PPI
- Supports transparent PNG and flattened JPEG output
- Embeds 300 PPI resolution metadata in both formats
- Processes source graphics entirely in the browser

The seam score is an inspection aid. Always confirm the centered-seam preview before production printing.
